    AI agent skill

    Target Indicators includes an Agent Skill, a set of instructions that teaches AI coding agents such as Claude Code how the package works and how to use it correctly. With the skill installed, you can ask an agent to set up or change target indicators in plain language. For example, you can ask it to add markers to your objectives that stick to the screen edge, or to add a compass bar like the one in Apex Legends. The agent then follows the package's recommended setup instead of working it out from the source code.

    You don't need the skill to use Target Indicators, and AI agents don't need it either. Agents can still use the package without the skill by reading its scripts and samples, but with the skill they finish tasks faster and more accurately.

    What the skill covers

    The skill gives an agent a short overview of the package and points it to more detailed guidance when a task needs it. It explains how the Target Indicator Manager and the sample visual indicators work together, and how to set up screen-edge indicators and compass tapes the same way the sample scenes do.

    It also covers the TargetIndicatorManager API for tracking targets, choosing and sizing a boundary so indicators stay clear of your HUD, and styling indicators with prefab variants. When something goes wrong, such as indicators that don't appear or that lag behind the camera, the skill helps the agent find the cause.

    The skill is located in Assets/Target Indicators/AI/Skills/target-indicators/. The agent reads SKILL.md first, and only reads the files in the references folder when a task needs more detail.

    Make the skill available to your agent

    Agents load skills from their own skills folder, so you need to copy the skill to where your agent looks for it.

    For Claude Code, copy the Assets/Target Indicators/AI/Skills/target-indicators folder to .claude/skills/target-indicators in your project's root folder, which is the folder that contains Assets. For other agents, refer to your agent's documentation to find where it loads Agent Skills from.

    After you update Target Indicators, copy the folder again so your agent uses the latest version of the skill.

    Tip

    To create and edit scenes, an agent needs access to the Unity Editor, for example through the Unity CLI and its MCP server. Without Editor access, an agent can still write scripts that use Target Indicators, but you'll need to set up the scene yourself.

    You don't need to mention the skill when you ask for something. Agents that support skills decide when to use one based on your request.

    Performance

    To measure the skill, an AI agent was given the same three tasks with and without the skill, and ran each task three times in each mode. The agent was Claude Opus 5.5 at medium effort in Claude Code, working in a new project with Target Indicators imported.

    Each task started from a scene prepared for it, and the agent received the prompt exactly as written below. For the hard task, the scene had one setting changed so that indicators stopped appearing, and the prompt didn't say which one.

    Task Prompt
    Simple i've got 3 cubes, Objective1 2 and 3. put waypoint markers on them that stick to the edge of the screen with an arrow when they're off screen
    Medium add a compass bar across the top of the screen like in apex that shows where Flag_Red and Flag_Blue are
    Hard my target indicators stopped showing up. the targets are still being added in OnEnable by the setup script but no markers appear on screen at all, no errors either. can you figure it out

    The following table compares the median results without the skill and with it. Agent steps are the number of requests the agent made to the model, and input tokens measure how much new content it read while exploring the project.

    Task Success rate Time Agent steps Input tokens
    Simple 83% to 100% 69s to 52s (25% faster) 14 to 11 (21% fewer) 53% fewer
    Medium 100% to 100% 160s to 85s (47% faster) 27 to 18 (33% fewer) 37% fewer
    Hard 100% to 100% 64s to 46s (28% faster) 11 to 11 (same) 44% fewer
    Average 6 points higher 33% faster 18% fewer 45% fewer

    With the skill, the agent completed every task and finished faster. It read much less of the project because it didn't need to study the package's source code to find the right setup. Its results were also closer to the recommended setup, for example adding boundary padding so indicators sit inside the screen edge, and giving targets that need to be told apart their own colored markers.

    Note

    These results come from a small number of runs with one agent and model, and they vary between agents, models, and projects. Simple tasks often succeed without the skill, so the main benefit is a faster and more consistent result.
